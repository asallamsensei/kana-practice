    Cómo se guarda tu avance

    Se guarda localmente en este navegador y en este dominio. Otro navegador, el dominio de GitHub Pages o un archivo HTML descargado pueden tener registros separados. Usa exportar/importar para trasladarlos; no hay sincronización automática.

    La importación añade registros nuevos. Solo reemplaza registros existentes si lo marcas; no borra otros registros del navegador. No recupera partidas antiguas que nunca se guardaron. Cierra las otras pestañas de práctica antes de restaurar para evitar que sobrescriban el avance importado.

    Las versiones antiguas de Oraciones se conservan en la copia, pero el resumen usa únicamente la más reciente por bloque. Los datos temporales de caché y los códigos de acceso no se incluyen.
